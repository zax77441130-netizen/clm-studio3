Admin

CLM 可交付版後台

這版把前台文案、SEO 模板、作品模板、媒體規則、fallback 與 schema 都放進可編輯資料結構，之後正式上線到網域也能繼續在後台調整。

0. 操作提醒

1. 先改全域內容 / 內容頁 / SEO / 模板
2. 再整理服務、作品與媒體
3. 作品區記得按「套用目前作品」與「套用目前媒體」
4. 最後按「一鍵儲存全部內容」
打開 SEO 檢查頁

1. 前端全域內容

品牌名、首頁主副標、關於與聯絡的主要內容。這些是正式前台會直接用到的內容。

尚未選擇 Logo
尚未選擇首頁封面圖

2. 聯絡方式與連結

LINE / Facebook / Instagram / Email / 其他自訂連結都在這裡管理。

3. SEO 基本設定與各頁正式內容

這一區是目前實際套用在前台的 SEO 內容，不是模板。模板請看下一區。

尚未選擇 SEO 圖片

4. SEO 模板 / 示範格式

這一區是給客戶看的填寫示範，不會直接強塞到前台正式內容。可把它當成「後台內建填寫說明」。

正式前台內容：改上面 SEO 正式欄位後，前台會直接更新
模板示範內容：改這區是為了教對方怎麼填，不會直接覆蓋前台
作品模板：教對方怎麼寫標題、摘要、詳細介紹、技術標籤與作品 SEO
媒體模板：教對方怎麼寫 alt / title / caption，以及圖片、影片、embed 的建議格式

5. 前台內容區塊優化

這區是首頁 / 關於 / 服務 / 聯絡的前台結構文案。可改，但仍維持後端可編輯，不會寫死在前端。

6. Services 管理

每一列就是一個服務。直接改標題和描述即可。

7. 作品集管理

作品標題、摘要、詳細介紹、技術標籤、作品頁 SEO 都在這裡。照模板填即可，不用自己亂猜。

尚未選擇作品封面

8. 作品媒體

圖片 / 影片 / embed 都可以管理。alt、title、caption 都能一起維護。

Embed 使用方式：請把類型切到 embed，貼入合法 iframe。現在只允許 YouTube、Vimeo、Google Maps 的 https iframe；script、事件屬性（onclick / onerror 等）、javascript:、data:、以及其他網域都會被後端拒絕。

尚未選擇媒體

9. Schema 與 fallback 規則

這區控制結構化資料與預設補位邏輯，讓作品頁、SEO 與分享圖在資料不完整時也能正常運作。
